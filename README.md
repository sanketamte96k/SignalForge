# SignalForge

Multi-timeframe intraday trading signal system.

## Goal

SignalForge is designed to analyze market data across multiple
timeframes and generate manual trading signals.

## Core Principles

- Multi-timeframe analysis
- Intraday first
- Backtesting before real-world use
- Risk management
- No automatic order execution
- Final BUY/SELL decision remains with the user
